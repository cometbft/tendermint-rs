# ML-DSA-65 fixtures

`fixture.json` is generated by `generator/main.go` against CometBFT v0.40.0
(the Go reference implementation, using cloudflare/circl). It contains:

- `key`: an ML-DSA-65 key derived from the seed `01 02 .. 20`, its address,
  JSON (`cometbft/PubKeyMlDsa65`) and protobuf encodings, a signature over
  `msg_hex`, and a signature over the same message under a non-empty context
  (`ctx_sig_hex`), which must be rejected as a pure ML-DSA signature.
- `light_block`: a signed header and validator set with one ML-DSA-65 and one
  Ed25519 validator, both signing. Go's `VerifyCommitLight` and `VerifyCommit`
  accept it before the file is written.

To regenerate:

```sh
cp go.mod.example go.mod   # edit the replace path to a cometbft v0.40.0 checkout
go mod tidy
go run . > ../fixture.json
```
